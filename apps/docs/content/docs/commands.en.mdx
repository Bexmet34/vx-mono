# Command References

Veyronix uses modern Discord APIs and has built all its commands upon the Slash (`/`) structure. This way, when you start typing a command, the required information (parameters) is visually presented to you by Discord.

## ⚙️ General and Settings Commands

- `/setup` - Starts the wizard allowing you to set up all core systems of Veyronix in your server.
- `/ping` - Shows the bot's current latency and API status.
- `/istatistik` - Displays the general system and hardware usage statistics of the Veyronix bot.
- `/dil` - Sets the language the bot will use in your server (Turkish, English, etc.).

## 🔊 Temporary Voice (VoiceForge) Commands

*Note: Actions that can be performed via the voice panel can also be done with commands.*
- `/ses-kilitle` - Locks the voice channel you are currently in.
- `/ses-ac` - Opens your locked voice channel to everyone.
- `/ses-limit <number>` - Sets the limit for how many people can join the room.
- `/ses-isim <new_name>` - Changes the name of your room.

## 📝 Community & Engagement

- `/cekilis-baslat` - Allows you to quickly create a giveaway.
- `/cekilis-bitir` - Immediately ends an ongoing giveaway.
- `/drop-at` - Manually drops a point (Drop) box into the chat.
- `/ticket-kur` - Sends the Support System menu to the selected channel.

## ⚔️ Albion Online Commands

- `/albion-eslestir <player_name>` - Links your Discord account with your in-game character.
- `/zvz-parti-kur` - Creates a new ZvZ operation plan.
- `/killboard-ayarla` - Configures the channel where Killboard notifications will be sent.
