# Slash (/) Command Guide

Due to Veyronix's design philosophy, all core settings and module configurations of your server are done via the **[Web Dashboard](/docs/dashboard)**. However, you might not want to switch to the browser when you are playing a game, chatting, or need to take an urgent action.

This is where Veyronix's next-generation Discord Slash (`/`) commands come into play. When you start typing a command, Discord automatically lists the information (parameters) you need to enter visually.

<Callout type="info">
  **Permission Check:** Some commands (e.g., Starting a Giveaway, Setup) can only be seen and used by people with Administrator privileges on the server or the "Bot Staff" role determined from the dashboard.
</Callout>

---

## ⚙️ Core System Commands

Used to test the bot's operability and trigger quick setups.

- **`/setup`**
  - *What It Does:* When you first add the bot to the server or want to reset settings, it launches an automated wizard that creates the necessary channels and base roles for you in seconds. Only founders can use this.
- **`/ping`**
  - *What It Does:* Allows you to check the bot's current latency (ms), database response speed, and active server shard statistics.
- **`/istatistik` (Statistics)**
  - *What It Does:* Reports how many servers the bot is serving, active CPU/RAM usage, and uptime.

## 🔊 VoiceForge (Voice Management) Commands

Members who open their own rooms may also choose to use the command line instead of clicking the buttons in the text channel. These commands only work when you are **inside** a VoiceForge temporary room and you are the **owner** of that room.

- **`/ses-isim`** `[new_name]`
  - Changes the name of your channel in seconds. Names caught in the profanity/insult filter are rejected by the bot.
- **`/ses-limit`** `[number]`
  - Sets the maximum number of people who can enter the room (between 0 and 99). When the limit is reached, others cannot enter the room.
- **`/ses-kilitle`** & **`/ses-ac`** (Lock/Unlock)
  - Completely closes the doors of the room to outside entries or opens them again.
- **`/ses-gizle`** & **`/ses-goster`** (Hide/Unhide)
  - Makes the room invisible on the server list or makes it visible again.
- **`/ses-at`** `[user]` (Kick)
  - Allows you to kick a disturbing person from your channel by tagging them.
- **`/ses-devret`** `[user]` (Transfer)
  - If you need to leave but don't want the room to disappear, you transfer the ownership of the room (the authority to use the buttons on the control panel) to someone else inside.

## 🎉 Interaction and Community Commands

Tools used by administrators or event managers to liven up the server.

- **`/cekilis-baslat`** `[duration] [prize] [winner_count]` (Start Giveaway)
  - *How It Works:* Starts a giveaway that will last for the duration you specify (e.g., 10m, 1h, 1d). Participants join by clicking the button/reaction left on the message.
- **`/cekilis-bitir`** `[message_id]` (End Giveaway)
  - *How It Works:* Used to urgently conclude a giveaway that hasn't expired yet.
- **`/cekilis-reroll`** `[message_id]` (Reroll)
  - *How It Works:* If the person who won the giveaway doesn't meet the conditions, it allows a new winner (backup) to be selected.
- **`/drop-at`** `[amount] [reward_type]` (Drop Box)
  - *How It Works:* Instead of waiting for the bot's automatic drops, it allows you as an administrator to instantly throw a reward box into the chat. Perfect for instantly igniting the chat.

## ⚔️ Albion Online ZvZ Commands

Tools that coordinate Guild battles and killboard records.

- **`/albion-eslestir`** `[in_game_name]` (Link Account)
  - Allows players to link their Discord accounts with their in-game Albion characters. If successful, the user's Discord name is edited according to the Albion tag.
- **`/zvz-parti-kur`** `[target] [time]` (Create Party)
  - Creates a CTA (Call to Arms) announcement. Launches a buttoned party interface where joining members can choose whether they will play Tank, Healer, or DPS roles.
- **`/guild-guncelle`** (Update Guild)
  - Bypasses the bot's cooldown (API Refresh) and forces it to instantly connect to the Albion API and update the roles and names on the server. Used to quickly weed out spies.
