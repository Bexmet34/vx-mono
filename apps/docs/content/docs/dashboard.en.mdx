# Web Dashboard (Control Panel)

Instead of using complex and long commands in Discord to configure all of the bot's settings, you can do it via our modern and fast web interface.

## Logging into the Panel

1. Go to [veyronix.com.tr](https://veyronix.com.tr).
2. Click the **Login** button in the top right corner and connect with your Discord account.
3. Servers where you have Administrator permissions will automatically be listed on the panel.

## Setting Modules

Main modules you can use on the Dashboard:

- **General Settings:** Server prefix, language settings, and staff roles.
- **Temporary Voice (VoiceForge):** The category where voice channels will be created and panel settings.
- **Registration System:** Automatically assigned roles and the registration welcome channel.
- **Welcome / Goodbye:** Custom embedded image or text messages to be sent to joining/leaving members.
- **Auto Role:** Initial roles given unconditionally to those joining the server.
- **Ticket Settings:** Support system managers and transcript channels.
- **Premium:** If your server has Premium features, the area where extra features are activated.
