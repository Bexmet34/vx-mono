# Registration System

Unlike traditional registration bots, Veyronix offers a completely modern and loggable registration infrastructure.

## Features

- **Button Registration:** Members can register quickly simply by clicking buttons (Male, Female, etc.) without entering complex commands.
- **Name Formatting:** The registered person's name is automatically changed according to the format you specify (e.g., `[Tag] Name | Age`).
- **Welcome and Log Messages:** You can send custom image welcome messages to newcomers and send a notification to the log channel when the registration is complete.
- **Unregistered Role Automation:** The first person joining the server is automatically given the unregistered role, and this role is removed once registration is completed.

## Registration Setup

Go to the **Registration System** tab on the web dashboard:
1. Select the initial role to be given to unregistered users.
2. Select the registered roles to be assigned, such as Male/Female or Member.
3. Determine the staff role that will perform the registration (Registration Officer).
4. Select the channel where the registration panel will be sent (e.g., `#register-here`) and save.

As soon as you save the settings, an elegant registration menu will be sent to the channel you specified.
