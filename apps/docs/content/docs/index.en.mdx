# What is Veyronix?

Veyronix is far more than a simple Discord bot. It is an **enterprise-grade community management and automation platform** designed to grow, manage, and secure your server.

It operates on an advanced monorepo architecture with a sharded microservices infrastructure that easily handles high loads. This ensures thousands of real-time interactions are processed with zero latency and maximum performance.

<Callout type="info">
  **Architecture Insights:** The Veyronix system is composed of multiple isolated yet fully integrated systems: core bot operations (Partikür), support and ticketing (VX Support), and a modern web dashboard (VX Web).
</Callout>

## Featured Modules

Our platform provides four main ecosystems working seamlessly together:

- **VoiceForge (Dynamic Voice System):** Eliminates traditional channel clutter by allowing members to create and manage their own private voice channels on the fly via a dedicated panel.
- **Registration & Security:** A multi-layered registration system featuring button interfaces, detailed logging, auto-naming, and strict security barriers.
- **Albion Online ZvZ Engine:** The world's most advanced Albion Online integration. Direct Discord integration for Guild synchronization, automated Killboard tracking, and deep ZvZ statistics analysis.
- **Community & Engagement:** Tools that maximize server engagement, including modern ticket systems, transparent giveaways, and drop (point/economy) mechanics.

## Quick Setup

Integrating the Veyronix ecosystem into your server takes only seconds. You can visually configure everything via our custom web dashboard.

<Steps>
<Step>
### Login to our Web Dashboard
Navigate to [veyronix.com.tr](https://veyronix.com.tr) and log in securely with your Discord account.
</Step>

<Step>
### Select Your Server
Select a server where you have Administrator permissions and click "Add Veyronix" to authorize the integration.
</Step>

<Step>
### Complete the Setup Wizard
Use the interactive **Setup Wizard** to configure base roles and logging channels in seconds.
</Step>
</Steps>

<Callout type="warn">
  After installation, ensure that the **"Veyronix"** bot role is placed higher than any roles it needs to manage (e.g., Unregistered role, Member role) in your server settings.
</Callout>

For detailed module configurations, use the sidebar menu to navigate to the specific documentation pages.
