# Web Dashboard (Yönetim Paneli)

Botun tüm ayarlarını Discord içindeki karmaşık ve uzun komutlarla yapmak yerine, modern ve hızlı web arayüzümüz üzerinden gerçekleştirebilirsiniz.

## Panele Giriş

1. [veyronix.com.tr](https://veyronix.com.tr) adresine gidin.
2. Sağ üst köşedeki **Giriş Yap** butonuna tıklayarak Discord hesabınızla bağlanın.
3. Yönetici yetkisine (Administrator) sahip olduğunuz sunucular panelde otomatik olarak listelenecektir.

## Ayar Modülleri

Dashboard üzerinde kullanabileceğiniz ana modüller:

- **Genel Ayarlar:** Sunucu prefixi, dil ayarları ve yetkili rolleri.
- **Geçici Ses (VoiceForge):** Ses kanallarının açılacağı kategori ve panel ayarları.
- **Kayıt Sistemi:** Otomatik verilecek roller ve kayıt karşılama kanalı.
- **Karşılama / Uğurlama:** Giren çıkan üyelere atılacak özel embed resimli veya metin mesajları.
- **Oto Rol:** Sunucuya katılanlara koşulsuz verilecek başlangıç rolleri.
- **Ticket Ayarları:** Destek sistemi yöneticileri ve transkript kanalları.
- **Premium:** Eğer sunucunuz Premium özelliklere sahipse, ekstra özelliklerin aktif edildiği alan.
