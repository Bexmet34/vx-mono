# Welcome to Veyronix Docs

Veyronix is an advanced Discord automation ecosystem built specifically for gaming communities. 

## Core Features

- **VoiceForge (Temporary Channels):** Create dynamic voice channels with a 15-button control panel.
- **Registration System:** Modal-based automated registration and role assignment.
- **Albion Online Integration:** Live killboards, ZvZ party finder, and player statistics directly in your server.
